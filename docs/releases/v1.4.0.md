# v1.4.0 — automation, safety and simpler installation

## User update steps / Kroki po aktualizacji

1. **HACS:** update **Hoymiles HIT xxL G3 Modbus** to version **1.4.0**.
   **PL:** zaktualizuj integrację w HACS do wersji **1.4.0**.
2. **Home Assistant:** restart once after HACS finishes. Managed dashboard and
   EMS files are synchronized automatically; files modified by the user are
   preserved. If Home Assistant shows a package Repair, follow it and perform
   one additional restart. **PL:** po aktualizacji wykonaj jeden restart.
   Zarządzane pliki zsynchronizują się bez nadpisywania własnych zmian. Jeżeli
   pojawi się Naprawa dotycząca pakietów, wykonaj instrukcję i uruchom HA jeszcze
   raz.
3. **ESP32 / ESPHome:** no firmware rebuild is required for existing users;
   firmware **v1.3.3** remains runtime-compatible. Rebuild only if you want the
   new optional ESPHome adoption metadata embedded in the device. HACS never
   flashes ESP32. **PL:** dotychczasowego ESP32 nie trzeba wgrywać ponownie;
   firmware **v1.3.3** pozostaje zgodne. Kompilacja jest opcjonalna wyłącznie
   dla nowych metadanych adopcji ESPHome. HACS nie aktualizuje ESP32.
4. **Verification / Weryfikacja:** open the integration device and check
   **Installation status / Stan instalacji**. Follow a displayed Home Assistant
   Repair, if present, until the status is **Ready / Gotowe**. Existing
   automatic modes remain off after the update and RCEm remains in observation
   mode by default. **PL:** sprawdź **Stan instalacji** oraz ewentualne Naprawy.
   Automatyki pozostają wyłączone, a RCEm domyślnie działa tylko obserwacyjnie.

## Highlights / Najważniejsze zmiany

- Rebuilt RCE as an automatic optimizer using all available price blocks for
  today and tomorrow, with home/night protection, BMS and parallel-system
  limits, natural-PV export accounting and no fixed minimum selling price.
- Added automatic tariff-aware grid charging for G11, G12, G12w and G13,
  presets for five Polish distribution operators, a manual profile, physical
  charging lead time and savings statistics.
- Added experimental **RCEm 253 V+** with four-day L1/L2/L3 history, Solcast and
  LOAD-aware headroom, optional morning pre-discharge and user-capped export
  control. RCEm starts in observation-only mode and never changes certified
  protections, three-phase unbalance or GCF.
- Added scheduled LiFePO4 storage balancing with PV priority, grid completion,
  a slow 99–100% stage and restoration of the previous settings.
- Corrected the four-day household model to use dedicated true LOAD rather than
  double-counting PV-to-LOAD and battery-to-LOAD flows.
- Added revenue/PV-production views, mobile notifications, tariff statistics,
  installation diagnostics and an update-safe bilingual dashboard.
- Simplified first installation with automatic managed assets, ESP32
  preselection, a localized **Installation status**, Home Assistant Repairs and
  a bilingual quick-start guide.
- Changed the license for v1.4.0 and later to PolyForm Noncommercial 1.0.0.
  Releases through v1.3.4 remain MIT-licensed.

## Validation / Walidacja

- HACS layout, manifest, translations, fresh installation and dashboard assets
  validated.
- 276 Polish/English entities validated.
- ESPHome 2026.7.3 configuration validated for both public entry files.
- Deterministic RCE, tariff and RCEm suites passed.
- The exhaustive cross-system automation matrix passed **2064/2064** scenarios
  for 10, 15 and 20 kW systems and a parallel 2 × 20 kW system.

RCEm is simulation-tested but still experimental until confirmed on a real
high-voltage export site. Revenue and tariff values are operational estimates,
not settlement invoices. Bundled tariff prices are a 2026 snapshot; users must
compare them with their current contract.
