# v1.4.6 — diagnostics and clean home-energy history

## User update steps / Kroki po aktualizacji

1. **HACS:** update **Hoymiles HIT xxL G3 Modbus** to version **1.4.6**.
   **PL:** zaktualizuj integrację **Hoymiles HIT xxL G3 Modbus** w HACS do
   wersji **1.4.6**.
2. **Home Assistant:** restart once after HACS finishes. The managed dashboard,
   EMS package and frontend card are refreshed automatically. Existing
   dashboard customizations remain protected by the normal migration backup.
   **PL:** po zakończeniu aktualizacji wykonaj jeden restart Home Assistanta.
   Zarządzany dashboard, pakiet EMS i karta frontendowa zostaną odświeżone
   automatycznie, a dotychczasowe modyfikacje chroni standardowa kopia migracji.
3. **ESP32 / ESPHome:** no firmware rebuild is required. This release changes
   the Home Assistant integration, managed EMS package, dashboard and
   documentation only; the compatible ESPHome package remains **v1.4.4**.
   HACS does not flash ESP32. **PL:** nie trzeba ponownie kompilować ani wgrywać
   ESP32. Wydanie zmienia integrację Home Assistanta, zarządzany pakiet EMS,
   dashboard i dokumentację; zgodny pakiet ESPHome pozostaje w wersji
   **v1.4.4**. HACS nie aktualizuje ESP32.
4. **Verification / Weryfikacja:** confirm **Installation status / Stan
   instalacji = Ready / Gotowe**. In LOAD/EPS, the 30-day home-consumption chart
   starts a new clean series from the real phase LOAD; previous inflated
   statistics are intentionally not copied. As an administrator, open the last
   Diagnostics view and verify that **Download diagnostic ZIP** produces one
   archive. **PL:** sprawdź **Stan instalacji = Gotowe**. W LOAD/EPS wykres
   zużycia domu rozpocznie nową, czystą serię z rzeczywistej mocy faz LOAD;
   poprzednie zawyżone statystyki celowo nie są kopiowane. Jako administrator
   otwórz ostatnią zakładkę Diagnostyka i sprawdź pobranie jednego ZIP-a.

## Added / Dodano

- Native Home Assistant **Download diagnostics** support with integration and
  firmware versions, entity coverage, optimizer/EMS state and 24 hours of
  significant control history.
- An administrator-only dashboard button that builds a privacy-filtered ZIP in
  memory and downloads it directly, without leaving a file in `/config`.
- An optional Terminal & SSH collector for extended Core, ESPHome, Modbus and
  host diagnostics.
- Bilingual instructions explaining what to attach, the exact fault time to
  include and the support address `info@kaluzaaa.com`.
- Natywną diagnostykę Home Assistanta, pobieranie odfiltrowanego ZIP-a jednym
  kliknięciem oraz opcjonalny rozszerzony kolektor dla Terminal & SSH.

## Fixed / Naprawiono

- Home-consumption energy is now integrated from the clean per-phase LOAD power
  (registers 2170–2172), excluding inverter self-consumption and conversion
  losses reported by the aggregate inverter counters.
- The LOAD/EPS 30-day chart uses a new long-term statistics source. It starts
  clean after the update instead of displaying the old inflated 60–70 kWh/day
  history.
- RCE keeps the stable compatibility entity but receives the corrected daily
  home-energy value for future samples.
- Energia domu jest liczona z rzeczywistej sumy mocy faz LOAD, bez zużycia
  własnego falownika i strat przetwarzania. Wykres rozpoczyna nową czystą
  historię, a zgodna wstecznie encja RCE otrzymuje poprawne kolejne próbki.

## Documentation / Dokumentacja

- The README now presents the project as a local, explainable EMS while keeping
  the existing Hoymiles/Modbus repository name and search terms.
- Module scope, external-data requirements, financial-estimate disclaimer,

  control is enabled.

  Doprecyzowano zależności, bezpieczeństwo, charakter estymacji finansowych oraz
  kontrolę przed pierwszym włączeniem automatyk.
