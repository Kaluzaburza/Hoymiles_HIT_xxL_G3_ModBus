# v1.5.0 — Aurora EMS planning and safety release

## User update steps / Kroki po aktualizacji

1. **HACS:** update **Hoymiles HIT xxL G3 Modbus** to **v1.5.0**.
   Zaktualizuj integrację **Hoymiles HIT xxL G3 Modbus** do **v1.5.0** w HACS.
2. **Home Assistant:** restart Home Assistant once. The managed EMS package,
   bilingual Aurora dashboard and frontend cards synchronize automatically.
   If **Installation status / Stan instalacji** or **Repairs / Naprawy** asks
   for another restart, validate the configuration and perform it; this can
   occur when updating directly from an older release.
   Uruchom Home Assistant ponownie jeden raz — pakiet EMS, dashboard Aurora
   PL/EN i karty frontendowe zsynchronizują się automatycznie. Jeżeli potem
   **Stan instalacji** albo **Naprawy** poprosi o kolejny restart, sprawdź
   konfigurację i wykonaj go; może to wystąpić przy aktualizacji ze starszej
   wersji.
3. **ESP32 / ESPHome:** no firmware rebuild is required for this release.
   Ta wersja nie wymaga ponownej kompilacji ani wgrywania ESP32.
4. **Verification / Weryfikacja:** confirm **Installation status / Stan
   instalacji = Ready / Gotowe**. Review the basic and expert views before
   enabling automatic writes; commission RCEm in observation mode first.
   Sprawdź stan instalacji `Gotowe`. Przed włączeniem automatycznego sterowania
   przejrzyj widok podstawowy i ekspercki, a RCEm uruchamiaj najpierw w trybie
   obserwacji.

## Highlights

- Aurora dashboard with compact everyday views and optional expert data.
- RCE reserve enforced at full SOC resolution in every selected export block,
  explicit day-three reserve reasoning, avoided-import terminal value and
  separate gross/net benefit.
- Tariff charging with a real rolling horizon, conservative missing-tail
  fallback and learned effective Grid Charge power.
- RCEm 253 V+ with interval Solcast, weekday/weekend LOAD profiles and
  independent battery-headroom calculations for each voltage-risk window.
- Single EMS owner, stale-data fail-closed gates, BMS/GCF/parallel limits,
  command acknowledgement, latching/dwell and safe Self-Use fallback.
- Updated safety/audit matrix, 2064-scenario exhaustive test report and a new
  four-panel dashboard overview.

Automated release validation: **2064/2064 exhaustive EMS scenarios passed**.

## Important boundary

The project implements and documents EMS functions that can support technical
acceptance. It is not a formal certificate for the inverter, battery or the
complete electrical installation, and it never replaces certified grid
protection settings.
