# v1.4.4 — dashboard clarity, persistent controls and optimizer stability

## User update steps / Kroki po aktualizacji

1. **HACS:** update **Hoymiles HIT xxL G3 Modbus** to version **1.4.4**.
   **PL:** zaktualizuj integrację **Hoymiles HIT xxL G3 Modbus** w HACS do
   wersji **1.4.4**.
2. **Home Assistant:** restart once after HACS finishes. The managed dashboard,
   EMS package and frontend cards are refreshed automatically. Existing
   dashboard customizations remain preserved. **PL:** po aktualizacji wykonaj
   jeden restart Home Assistanta. Zarządzany dashboard, pakiet EMS i karty
   frontendowe odświeżą się automatycznie, a własne modyfikacje zostaną
   zachowane.
3. **ESP32 / ESPHome:** this release changes `packages/battery.yaml`. Refresh
   the top-level `hoymiles-inverter.yaml`, confirm that the remote package is
   pinned to **v1.4.4**, then validate, compile and upload the firmware. HACS
   does **not** flash ESP32. **PL:** odśwież `hoymiles-inverter.yaml`, sprawdź
   przypięcie do **v1.4.4**, następnie zweryfikuj, skompiluj i wgraj firmware.
   HACS **nie** aktualizuje ESP32.
4. **Verification / Weryfikacja:** confirm **Installation status / Stan
   instalacji = Ready / Gotowe**, verify battery capacity, open the new charts
   and check that **EMS control conflict / Konflikt sterowania** is off.
   Notification and automation switches should retain their selected state.
   **PL:** sprawdź stan instalacji, pojemność baterii, nowe wykresy, brak
   konfliktu EMS oraz zachowanie ustawień powiadomień i automatyk.

## Highlights / Najważniejsze zmiany

- High-contrast native Home Assistant charts now cover power flow, LOAD/EPS,
  PV strings, grid, battery, revenue and PV production.
- The main graph uses green PV, red home, yellow grid and blue battery; the PV
  view uses a red-to-green PV1–PV4 palette.
- Responsive cards improve desktop and phone layouts without requiring
  Mushroom for their structure.
- A new EMS control-owner sensor and conflict detector make competing
  automatic modes visible.
- User-selected helper states survive Home Assistant restarts, preventing
  notification and automation switches from silently returning to defaults.
- RCE and tariff recalculations are debounced; RCE, tariff and RCEm publish a
  new state only when their material result changes.
- Expired built-in tariff price tables safely block grid charging.
- Battery capacity now prefers inverter register 4102, with BMS register 1907
  retained as a fallback; RCEm and the power-flow card use the same physical
  capacity source.
- Licensing documentation now describes the current MIT license without
  obsolete version-by-version explanations.
