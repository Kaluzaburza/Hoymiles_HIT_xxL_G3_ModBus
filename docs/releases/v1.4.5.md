# v1.4.5 — tariff charging loop hotfix

## User update steps / Kroki po aktualizacji

1. **HACS:** update **Hoymiles HIT xxL G3 Modbus** to version **1.4.5**.
   **PL:** zaktualizuj integrację **Hoymiles HIT xxL G3 Modbus** w HACS do
   wersji **1.4.5**.
2. **Home Assistant:** restart once after HACS finishes. The managed EMS
   package is refreshed automatically and creates the internal target/slot
   memory used by the hotfix. **PL:** po aktualizacji wykonaj jeden restart Home
   Assistanta. Zarządzany pakiet EMS odświeży się automatycznie i utworzy
   wewnętrzną pamięć celu oraz okna.
3. **ESP32 / ESPHome:** no firmware rebuild is required. This hotfix changes
   only Home Assistant; the compatible ESPHome package remains **v1.4.4**.
   HACS does not flash ESP32. **PL:** nie trzeba ponownie kompilować ani wgrywać
   ESP32. Poprawka dotyczy wyłącznie Home Assistanta, a zgodny pakiet ESPHome
   pozostaje w wersji **v1.4.4**. HACS nie aktualizuje ESP32.
4. **Verification / Weryfikacja:** confirm **Installation status / Stan
   instalacji = Ready / Gotowe**. In the next planned cheap window, Grid Charge
   should start once and keep the same target until it is reached or the latched
   window ends. One stable EMS change should generate one push notification
   after 15 seconds. **PL:** sprawdź **Stan instalacji = Gotowe**. W następnym
   tanim oknie Grid Charge powinien uruchomić się raz i zachować ten sam cel do
   jego osiągnięcia albo końca zapamiętanego okna. Jedna stabilna zmiana EMS
   powinna utworzyć jedno powiadomienie po 15 sekundach.

## Fixed / Naprawiono

- The automatic tariff controller now freezes the target SOC, active action and
  complete contiguous slot end at cycle start.
- Live SOC, LOAD and forecast updates may extend an active plan but cannot
  shorten it and trigger a Grid Charge/Self-Use loop.
- A 1% start deadband and a 90-second minimum confirmation interval separate
  start and stop decisions.
- Push notifications require a stable state for 15 seconds and ignore no-op
  transitions.
- Automat taryfowy nie reaguje już natychmiastowym zatrzymaniem na chwilowe
  zniknięcie bieżącego bloku podczas ponownego przeliczenia planu.
