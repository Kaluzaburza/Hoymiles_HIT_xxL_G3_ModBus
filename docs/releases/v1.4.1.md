# v1.4.1 — HACS license-identification hotfix and complete v1.4 update

## User update steps / Kroki po aktualizacji

1. **HACS:** update **Hoymiles HIT xxL G3 Modbus** to version **1.4.1**.
   **PL:** zaktualizuj integrację w HACS do wersji **1.4.1**.
2. **Home Assistant:** restart once after HACS finishes. Managed dashboard and
   EMS files are synchronized automatically; user-modified files are preserved.
   If Home Assistant shows a package Repair, follow it and restart once more.
   **PL:** po aktualizacji wykonaj jeden restart. Jeżeli pojawi się Naprawa
   dotycząca pakietów, wykonaj ją i uruchom HA ponownie.
3. **ESP32 / ESPHome:** no firmware rebuild is required. Firmware **v1.3.3**
   remains runtime-compatible and HACS never flashes ESP32. **PL:** ponowne
   wgrywanie ESP32 nie jest wymagane; firmware **v1.3.3** pozostaje zgodne.
4. **Verification / Weryfikacja:** check **Installation status / Stan
   instalacji** and follow any displayed Repair until it reports **Ready /
   Gotowe**. New automatic modes remain disabled and RCEm remains in
   observation-only mode by default. **PL:** sprawdź **Stan instalacji** i
   ewentualne Naprawy. Automatyki pozostają wyłączone, a RCEm obserwacyjny.

## Hotfix

- Restores the official, byte-identical PolyForm Noncommercial 1.0.0 license
  text. GitHub and HACS can now identify the SPDX id instead of returning
  `NOASSERTION`.
- Contains all v1.4.0 functionality and no additional ESPHome runtime change.

## v1.4 highlights / Najważniejsze zmiany v1.4

- Automatic RCE optimization over all available blocks for today and tomorrow,
  protecting the house, night demand, outage reserve and BMS/inverter limits.
- G11/G12/G12w/G13 tariff-aware charging with Polish operator presets, manual
  mode, physical charging lead time and estimated savings.
- Experimental **RCEm 253 V+** with four-day phase-voltage history, Solcast and
  LOAD-aware headroom, optional morning pre-discharge and user-capped export
  regulation. It starts in observation-only mode and never changes certified
  protections, three-phase unbalance or GCF.
- Scheduled LiFePO4 storage balancing with PV priority, grid completion, a slow
  99–100% stage and restoration of previous settings.
- Correct dedicated-LOAD history, revenue/PV-production views, mobile
  notifications, installation diagnostics and an update-safe PL/EN dashboard.
- Simpler setup with automatic managed assets, compatible ESP32 preselection,
  Home Assistant Repairs and a bilingual quick-start guide.

## Validation / Walidacja

- Official license file hash matches the PolyForm source exactly.
- HACS layout, manifest, translations, fresh installation and dashboard assets
  validated.
- 276 Polish/English entities and both public ESPHome 2026.7.3 YAML files
  validated.
- Deterministic RCE, tariff and RCEm suites passed.
- Exhaustive multi-system automation matrix passed **2064/2064** scenarios.

RCEm remains experimental until confirmed on a real high-voltage export site.
Revenue and tariff figures are operational estimates, not settlement invoices.
Bundled tariff prices are a 2026 snapshot and must be compared with the user's
current contract.
