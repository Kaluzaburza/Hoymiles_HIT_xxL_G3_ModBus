# v1.4.3 — setup-status diagnostic hotfix

## User update steps / Kroki po aktualizacji

1. **HACS:** update **Hoymiles HIT xxL G3 Modbus** to version **1.4.3**.
   **PL:** zaktualizuj integrację w HACS do wersji **1.4.3**.
2. **Home Assistant:** restart once after HACS finishes so the corrected setup
   diagnostic and Repairs check are reloaded. **PL:** po zakończeniu
   aktualizacji wykonaj jeden restart Home Assistanta, aby przeładować
   poprawioną diagnostykę instalacji i Naprawy.
3. **ESP32 / ESPHome:** no firmware rebuild is required. HACS does not flash
   the ESP32, and this hotfix does not change ESPHome, Modbus polling or
   inverter control. **PL:** ponowna kompilacja ani wgrywanie firmware ESP32
   nie są wymagane; HACS nie wgrywa firmware, a ten hotfix nie zmienia ESPHome,
   odpytywania Modbus ani sterowania falownikiem.
4. **Verification / Weryfikacja:** open **Diagnostyka** and confirm that
   **Stan instalacji** reports **Gotowe / Ready** when the managed EMS package
   is loaded. The false package warning in Home Assistant Repairs should also
   disappear. **PL:** otwórz **Diagnostykę** i sprawdź, czy **Stan instalacji**
   pokazuje **Gotowe**, a fałszywe ostrzeżenie o brakującym pakiecie znika z
   sekcji Naprawy.

## Fixed / Poprawiono

- The setup-status sensor and Repairs check now use the existing
  `input_boolean.hoymiles_rce_discharge_enabled` helper instead of a helper
  name that was never created by the EMS package.
- A structural regression test verifies that the shared readiness sentinel is
  present in the distributed EMS package.
- Diagnostyka i Naprawy nie zgłaszają już braku pakietu, gdy automatyka EMS/RCE
  jest rzeczywiście załadowana.

## Validation / Walidacja

- release structure and generated assets: passed;
- RCE, tariff and RCEm deterministic tests: passed;
- exhaustive cross-system automation matrix: **2064/2064** scenarios passed;
- custom RCE card validation: passed;
- no ESP32 firmware or inverter-write behavior changed.
