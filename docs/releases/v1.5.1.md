# v1.5.1 — complete bilingual documentation

## User update steps / Kroki po aktualizacji

1. **HACS:** update **Hoymiles HIT xxL G3 Modbus** to **v1.5.1**.
   Zaktualizuj integrację **Hoymiles HIT xxL G3 Modbus** do **v1.5.1** w HACS.
2. **Home Assistant:** restart Home Assistant once so it loads the new
   integration metadata. The EMS package and frontend logic are unchanged. If
   updating from a release older than 1.5.0 and **Installation status / Repairs**
   requests another restart, validate the configuration and perform that second
   restart.
   Uruchom Home Assistant ponownie jeden raz, aby wczytał nowe metadane
   integracji. Pakiet EMS i logika interfejsu nie uległy zmianie. Jeżeli
   aktualizujesz wersję starszą niż 1.5.0, a **Stan instalacji / Naprawy** poprosi
   o kolejny restart, sprawdź konfigurację i wykonaj ten drugi restart.
3. **ESP32 / ESPHome:** no firmware rebuild is required. The compatible ESPHome
   package remains **v1.4.4**.
   Nie trzeba ponownie kompilować ani wgrywać ESP32. Zgodny pakiet ESPHome
   pozostaje w wersji **v1.4.4**.
4. **Verification / Weryfikacja:** open the repository page from HACS, select
   [English](https://github.com/Kaluzaburza/Hoymiles_HIT_xxL_G3_ModBus/blob/v1.5.1/README.md)
   or [Polski](https://github.com/Kaluzaburza/Hoymiles_HIT_xxL_G3_ModBus/blob/v1.5.1/README.pl.md), and confirm
   **Installation status / Stan instalacji = Ready / Gotowe**.
   Otwórz stronę repozytorium z HACS, wybierz pełną wersję angielską albo polską
   i sprawdź, czy **Stan instalacji = Gotowe**.

## What changed / Co zmieniono

- Replaced the mixed, nearly 1,000-line repository front page with concise,
  structured documentation.
- Added complete, equivalent English and Polish editions with a prominent
  language switch.
- Rewrote grammar and terminology in both languages and removed unclear
  marketing language.
- Preserved the full installation, wiring, update, EMS, parallel-system,
  diagnostics and safety guidance in both editions.
- Corrected the architecture description and standardized Modbus function 16
  (`0x10`) terminology.

- Zastąpiono mieszaną, liczącą niemal 1000 wierszy stronę repozytorium zwięzłą
  i uporządkowaną dokumentacją.
- Dodano pełne, równorzędne wersje angielską i polską z widocznym przełącznikiem
  języka.
- Poprawiono gramatykę i terminologię obu wersji oraz usunięto niejasne hasła
  marketingowe.
- W obu językach zachowano pełną instrukcję instalacji, okablowania,
  aktualizacji, automatyk EMS, systemów równoległych, diagnostyki i
  bezpieczeństwa.

The v1.5.0 EMS logic remains unchanged. Its exhaustive validation result is
still **2064/2064** scenarios passed.

Logika EMS z wersji v1.5.0 pozostaje bez zmian. Wynik jej pełnej walidacji nadal
wynosi **2064/2064** zaliczonych scenariuszy.
