# v1.4.7 — managed EMS restart guidance hotfix

## User update steps / Kroki po aktualizacji

1. **HACS:** update **Hoymiles HIT xxL G3 Modbus** to version **1.4.7**.
   **PL:** zaktualizuj integrację **Hoymiles HIT xxL G3 Modbus** w HACS do
   wersji **1.4.7**.
2. **Home Assistant:** validate the configuration and restart Home Assistant
   after HACS finishes. Then open the integration device and check
   **Installation status / Stan instalacji** plus
   **Settings → System → Repairs / Ustawienia → System → Naprawy**. If another
   restart is requested, validate the configuration and restart once more. This
   is expected when Home Assistant loaded the old YAML before the integration
   copied the updated package. **PL:** po aktualizacji sprawdź konfigurację i
   uruchom Home Assistant ponownie. Jeżeli wyświetli się prośba o kolejny
   restart, sprawdź konfigurację i wykonaj go jeszcze raz. Oznacza to, że Home
   Assistant wczytał stary YAML przed skopiowaniem nowego pakietu.
3. **ESP32 / ESPHome:** no firmware rebuild is required. The compatible ESPHome
   package remains **v1.4.4**. **PL:** nie trzeba ponownie kompilować ani wgrywać
   ESP32; zgodny pakiet ESPHome pozostaje w wersji **v1.4.4**.
4. **Verification / Weryfikacja:** confirm **Installation status / Stan
   instalacji = Ready / Gotowe**, attribute `restart_required: false`, EMS
   package version `1.4.7` and no Hoymiles Repair. **PL:** sprawdź stan `Gotowe`,
   `restart_required: false`, wersję pakietu EMS `1.4.7` i brak Naprawy Hoymiles.

## Fixed / Naprawiono

- Every managed Polish and English EMS package now exposes its release version.
- The integration compares the loaded package with its own version instead of
  assuming that an existing EMS helper proves the update is fully active.
- A bilingual Repair and Installation status explain the second restart when it
  is genuinely required, then clear automatically after the matching YAML is
  loaded.
- Missing `homeassistant: packages:` configuration remains a separate diagnosis
  with its original setup instructions.
- Każdy pakiet EMS PL/EN udostępnia teraz wersję wydania. Integracja wykrywa
  niewczytany jeszcze pakiet, pokazuje dokładny kolejny krok i automatycznie
  usuwa komunikat po poprawnym restarcie.

## Validation / Walidacja

- generated Polish/English package markers match the manifest version;
- fresh installation and managed-asset upgrade behavior are structurally tested;
- Python syntax, translations, dashboards and all deterministic optimizer tests
  are included in the release gate;
- exhaustive cross-system automation matrix: **2064/2064** passed;
- ESPHome firmware and Modbus polling are unchanged by this hotfix.
